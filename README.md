# Distributed Systems Labs

A collection of three hands-on distributed systems labs focused on **client-server design, networked application structure, and practical implementation exercises**.

Each lab contains an implementation together with a written technical report describing the exercise and results.

## What this repository demonstrates

- decomposition of distributed applications into client and server components
- implementation of networked communication workflows
- incremental development across multiple distributed systems exercises
- accompanying technical documentation for each lab
